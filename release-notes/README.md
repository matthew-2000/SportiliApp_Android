# Note per la produzione

Prima di avviare la produzione creare qui un file UTF-8, ad esempio `2.0.4-it-IT.txt`,
con le novità effettive della versione (1–500 caratteri). Fare commit insieme
al codice da provare e inserire il percorso nel parametro `notes_file`.
Le note storiche sotto `release/` rimangono inalterate.
